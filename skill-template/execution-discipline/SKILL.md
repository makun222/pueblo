# Execution Discipline

## 触发条件

当代码修复任务满足以下条件时触发：
- 根因已通过分析定位
- 修改点已明确
- 准备开始执行修改

## 执行规则

### 1. 先出 TODO 清单

在开始修改之前，列出所有需要修改的文件和具体修改内容。

### 2. 连续 edit

对每个文件执行连续的 `edit` 操作，不要中断去 `read` 已修改的文件。

### 3. 最后验证

所有修改完成后，统一进行验证（编译、测试）。

### 4. 禁止重复 read

不要在每次 edit 后 read 同一个文件来确认修改。信任 edit 返回的结果。

### 5. 目标 ≤2 轮完成

整个修复任务应在 2 轮对话内完成。
