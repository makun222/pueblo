# Context Recovery

## 触发条件

当用户输入满足以下任一条件时，立即执行此 skill：

1. **模糊指令**: "继续"、"修复"、"优化一下"、"按计划做"、"开始吧"
2. **纯代词引用**: "那个"、"它"、"这个"、"上面提到的"
3. **简短提示**: "然后呢"、"下一步"、"还有吗"
4. **任何无法从当前对话上下文明确推断用户意图的情况**

## 执行步骤

### Step 1: 调用 memo_recall

```
memo_recall(turnCount=3)
```

检索最近 3 轮的会话记忆，获取之前的任务计划和进度。

### Step 2: 检索文件系统

使用 glob 和 read 工具检查工作区中的关键文件：
- 最近的计划文件（如 `.kilo/plans/` 目录）
- 任何 TODO 或 CHECKLIST 文件
- 修改过的源文件

### Step 3: 重建上下文

基于 memo_recall 和文件检索结果，向用户确认：
1. 当前任务是什么
2. 已完成的部分
3. 剩余待完成的部分

### Step 4: 确认后继续

在用户确认重建的上下文后，继续执行任务。**禁止在上下文不清的情况下猜测用户意图。**
