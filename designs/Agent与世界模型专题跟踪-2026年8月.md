# Agent × 世界模型：前沿论文与趋势跟踪汇编

**跟踪时段：2026 年 7 月—8 月 27 日** ｜ 承接《AI大模型前沿技术汇编-2026年8月》2.2 节展开

---

## 一、为什么这是当前最值得跟踪的交叉方向

2026 年被业界普遍称为"**世界模型元年**"。北京智源研究院《2026 十大 AI 技术趋势》给出了一条主线判断：**我们正从"预测下一个词"跨越到"预测世界的下一个状态"（Next-State Prediction, NSP）**。

两条技术脉络在这一年加速合流：

- **Agent 一侧**：从"能对话、会生成"进化为"能自主完成长程任务、推动业务闭环"的执行型系统（国务院《关于深入实施人工智能+行动的意见》：到 2027 年智能体应用普及率超 70%）。但 Agent 的天花板开始受制于**缺少世界建模能力**——无法预演、无法低成本试错、无法在长程任务中维持世界状态的一致性。
- **世界模型一侧**：从 Sora 引发的"世界模拟器"讨论，演进到 Genie 3 实时可交互世界、NVIDIA Cosmos 物理 AI 平台；但"会预测"不等于"会行动"，世界模型需要 Agent 来"使用"，更需要以 Agent 为中心来设计。

两者交汇的核心命题：**世界模型从"预测世界"转向"服务 Agent"**，Agent 则借世界模型获得"想象、规划、低成本试错"的能力。全球资本同步涌入：2025—2026 年世界模型赛道融资总额超 50 亿美元（杨立昆 AMI Labs 10.3 亿美元种子轮创欧洲 AI 纪录，李飞飞 World Labs 融资超 10 亿美元）。

## 二、核心论文精读（按主题分六类）

### 2.1 世界模型评测的"智能体化"

**■ PlayWorld：让 Agent 像真实用户一样"试玩"世界模型**
- 机构：香港大学、香港中文大学、浙江大学、快手可灵团队（一作丁凯欣，通讯赵恒爽）
- 链接：arXiv 2608.13552 ｜ 项目 kxding.github.io/project/PlayWorld/ ｜ 数据/代码已开源
- **核心创新**：把评测单位从"固定动作序列"升级为"**场景相关的长程目标**"。固定轨迹只能保证所有模型收到相同按键，却无法保证它们到达相同视角——模型没真正到达目标视角，后续几何一致性评分就失去可比性。PlayWorld 因此引入 **Agent Player**（多模态模型 + 接口转换器），只给定"场景 + 长程目标"，让其在交互中自行调整操作，观察视频的几何一致性、交互正确性、事物演化合理性（如绕房一周回原点验证场景一致性、走入水中看是否激起水花）。
- **意义**：与 HarnessEval-W 互为印证——世界模型评测正从"黑箱分数"走向"可追溯的智能体化过程评测"。

**■ Beyond Final Scores：长程科研 Agent 的过程评测**
- 链接：HuggingFace 2608.13417
- 内容：系统评估 7 个前沿模型在 36 个长程 AI 研发任务中的表现。核心结论：**当前 Agent 更像"工程优化器"而非"完全自主研究员"**——能提出并实现可行方案，但跨运行结果波动大；强结果多来自已有方法的组合改造，真正的方法创新稀少；相似最终分数背后可能藏着完全不同的过程瓶颈；经验复用既可能帮助决策，也可能误导模型。
- **意义**：把 Agent 评测从"有没有做成"推进到"怎么做成、哪里失败、经验是否真的复用"。

### 2.2 以 Agent 为中心的世界模型新范式

**■ World Proxy：世界建模的未来，从预测世界转向服务 Agent**
- 机构：上海 AI Lab、浙江大学、新加坡国立大学（NUS）
- 链接：arXiv 2608.02713 ｜ 项目 worldbench.github.io/awesome-agentic-world-model
- **核心创新**：提出"以 Agent 为中心"的交互式**世界代理（World Proxy）**——位于 Agent 与真实环境之间，根据 Agent 的查询、动作或干预，返回执行结果、经验/技能、奖励或验证信号，按介入深度分三层：
  - **L1 推理时引导**：不改参数，只提供记忆/技能检索、执行模拟、验证反馈（成本低、可回滚）；
  - **L2 训练时优化**：生成优化信号参与 Agent 参数更新；
  - **L3 共同演化**：世界代理与 Agent 随真实环境反馈持续同步更新。
- **意义**：为"世界模型如何真正服务智能体"提供了路线图，被视为该方向的范式级转向。

### 2.3 世界模型的技术演进：持久记忆、连续时间与显式状态

**■ Alaya-EVOKE：持久记忆世界模型**
- 链接：HuggingFace 2608.13546 ｜ 项目 evoke-world.github.io/Evoke/
- 解决**长程生成、持续交互与持久记忆之间的冲突**——让世界模型在长时间运行中保持上下文与状态，而非只做短片段预测。

**■ Marionette：从"预测下一帧"到"维护可编辑世界状态"**
- 链接：HuggingFace 2608.14530
- 面向交互式游戏世界模型，解决长程生成中角色姿态、几何关系、遮挡关系的漂移。将世界模型拆为三部分：**显式 3D articulated world state 预测 → 固定渲染器计算几何与遮挡 → 扩散模型合成 RGB**。可在状态层直接施加地形碰撞、角色间距约束，减少穿地与角色分离。

**■ ODEWorld：首个连续时间具身世界模型**
- 机构：清华大学智能产业研究院（AIR）+ UC Berkeley BAIR
- 链接：arXiv 2607.27924
- 传统视觉世界模型以"帧"为单位认识时间，两帧之间发生什么、换帧率后如何预测、关键瞬间缺失如何还原，都无法回答。ODEWorld 直接学习世界**在每个时刻的演化方向与速度**，还原随真实物理时间连续演化的潜空间轨迹——解决"夹取瞬间"这类发生在两帧之间的关键动作。

**■ DreamX-Phi 1.0：机器人操作视频世界模型**（阿里）
- 链接：HuggingFace 2608.13489 ｜ 代码 github.com/AMAP-ML/DreamX-Phi
- 动作条件视频世界模型：给定当前帧 + 语言指令 + 动作序列，预测机器人执行后的视觉结果，可用于规划、仿真与策略评估。

**■ SparseWorld-TC：轨迹条件稀疏占用世界模型**（理想汽车）
- CVPR 2026 Oral。车企系世界模型代表，用稀疏占用表征做轨迹条件预测，兼顾物理精度与算力效率。同赛道小鹏 2026 上半年发布五份技术报告，署名来自预测式世界模型（PWM）、生成式世界模型（GWM）、AI 基础设施、基座模型四支团队——**车企内部"VLA 与世界模型双线并进"已是常态**。

### 2.4 Agent 自我进化：从模型参数转向外部系统

**■ Self-Improving Agents 综述（97 页）**：LSTM 之父 Jürgen Schmidhuber 署名
- 机构：吉林大学、KAUST、阿尔伯塔大学、瑞士 AI 实验室（IDSIA）等
- 链接：arXiv 2607.13104 ｜ 项目 selfimproving-agent.github.io ｜ 配套整理 312 篇论文
- **核心框架**：把"自我改进"划分为两大主线——**基础模型改进（FM Improvement）**与**脚手架改进（Scaffolding Improvement）**。关键判据：真正学会的东西必须能**跨任务复用**——一条规则、一个被修复的工具，哪怕不更新权重，也改变了 Agent 的未来。六大典型场景：软件工程、网页导航、游戏与战略推理、科学发现、具身控制、企业办公。
- **背景信号**：发布后一周 GitHub 获 200+ stars，X 上推荐帖约 800 likes——self-improving agent 已成海外研究圈新焦点。

**■ EnvHarness：让训练环境自己进化**（Google）
- 链接：HuggingFace 2608.19880 ｜ 代码 github.com/google-research/envharness
- 针对"人工构建环境在 Agent 变强后迅速不够难"的问题，让环境参与训练闭环：根据 Agent 的失败模式与能力变化动态生成/改造环境。Agent 训练从固定 benchmark 走向"课程学习 × 对抗演化"的长程过程。

**■ MemoHarness：进化发生在模型之外**
- 核心主张：模型本身保持不变，真正持续被调整的是模型外部那套控制系统（Harness）。将 Harness 拆为**六个可编辑维度**，开发阶段记录成败轨迹，再按案例适配到新任务。在终端操作、代码生成、金融分析三类任务报告提升（作者自认实验规模有限）。
- **意义**：把"进化"的对象从模型参数扩展到外部系统——对企业而言更易观察、测试与回滚，更接近可落地的工程形态。

**■ Knowledge-Centric Self-Improvement**（加州理工 Caltech）
- 链接：arXiv 2607.19592
- **反直觉结论**：与其把 Agent 改得更聪明，不如让它保持"一次性"、把会进化的东西换成**一个共享知识库**。仅靠"攒知识"协议，Agent 解题率不降反升（ARC-AGI 等四大基准，Haiku 4.5 下 43.8% vs 最强 Agent 基线 37.6%），且成本更低；知识资产能**零样本跨任务、跨模型家族迁移**。

### 2.5 Agent 可靠性与具身安全

**■ RUPA：把不确定性建模从"单步置信度"推进到"结构化执行风险"**
- 链接：HuggingFace 2608.16002 ｜ 代码 github.com/icip-cas/RUPA
- 将 Agent 执行过程建模为**依赖图**（推理状态、工具交互、环境反馈为节点，时间与语义依赖为边），在图上传播不确定性，捕捉风险如何沿轨迹累积放大；结合轨迹级行为特征输出整条 trajectory 的置信度。在 τ²-bench、Terminal-Bench-2、GAIA 上优于现有 UQ 方法，支持早期失败检测。

**■ 基础模型驱动具身智能体安全综述**（武汉大学）
- 链接：arXiv 2608.16843
- 当 LLM/VLM/VLA/世界模型进入机器人控制环路，安全问题不再是"是否被越狱"。以**信任边界**为中心提出五层十二攻击面框架（模型供应链、用户指令、上下文与记忆、物理语义环境、多模态感知、世界状态、内部推理、任务规划、动作接口等），基于 58 条攻击与 61 条防御记录。**"世界状态"首次被列为独立攻击面**。

### 2.6 长程能力与科学 Agent

**■ Intern-S2-Preview：科学 Agentic 基座模型**
- 链接：HuggingFace 2608.13505
- 面向科学发现：处理异构科学证据、调用科学工具与环境、在长任务周期中持续推进研究——"科研 Agent"正从论文综述工具走向可执行的研发闭环。

**■ Apodex 1.1：复杂工作的 Agentic Intelligence Scaling**
- 链接：HuggingFace 2608.23283 ｜ 代码 github.com/ApodexAI/FrontierAgent
- 关注工具使用、任务分解、长期状态管理与执行闭环，代表企业级 Agent 的共性需求：**在较长时间内维持上下文、调用工具并处理失败**。

**■ CUDAAgent / PrimeAgent**（承接汇编 2.2 节已有条目）
- CUDAAgent（清华+字节）：Agentic RL 直接写 GPU Kernel；
- PrimeAgent：ARC-AGI-3 达 95.5%，世界模型与程序合成结合的推理 Agent 标杆。

## 三、综述与统一框架（理解领域的四把钥匙）

1. **《World Models: A Comprehensive Survey》**（arXiv 2606.00133，26 位学者，百页）
   - **架构—方法论—推理范式—应用**四维分类法。提出"**想象链（Chain of Imagination）**"概念：与依赖自然语言的思维链不同，世界模型直接在潜空间模拟状态变化，形成扎根于时空与行动的推理——世界模型可能从"预测未来的模拟器"演变为"支持规划决策的推理引擎"。

2. **《面向具身智能的世界模型综述》**（2026.6.10）
   - 首次提出**功能—时间—空间三轴统一分类框架**，梳理从决策专用（Dreamer 系）到通用模拟器（Sora、V-JEPA 2）的演进脉络，并量化对比全球顶尖模型。

3. **李飞飞《A Functional Taxonomy of World Models》**
   - 核心论点：**世界模型不是一件事，是三件事**——① 渲染器（Rendering，商业化最成熟，但"好看≠对"）；② **模拟器（Simulation，公众关注度最低，却最关键，是连接前两者的桥梁）**；③ 规划器（Planning，最年轻最性感，但离真实部署差距最大）。三线正在融合，终点是统一世界模型。World Labs 的 Marble 可视为该框架下的第一步。

4. **亿欧智库《2026 世界模型行业研究报告》**
   - 世界模型已形成**六大差异化能力模块**：JEPA（表征预测）、物理 AI 基础设施（仿真平台）、3D 世界模型（空间智能）、生成式视频（交互仿真）、潜空间强化学习、主动认知推断（因果/反事实）。短期竞争、长期互补，尚无一家独大。

## 四、评论与观点集萃

- **李飞飞：训练机器人和训练大模型是两回事**（World Labs 收购 SceniX 后对话）
  - 世界模型的核心载体是 Large World Model；real-to-sim-to-real 训练链路、合成数据与评测体系，都需要与 LLM 时代截然不同的底层思路。

- **陶大程（大晓机器人）："世界模型的使命不是完整复制世界，而是精准支撑行动。"**
  - 代表产业界务实立场：不追求"复制宇宙"，追求"足够支撑 Agent 行动的最小充分模型"。

- **36 氪《AI 造世界，难在第二步》**：分析"生境"架构——**状态模型**（维护对象、几何、关系、约束与历史）+ **行动模型**（学习目标、动作与未来状态的关系）+ **执行引擎**（生成、修改、渲染、验证并回写世界）。与 Coding Agent 直接操纵 Blender/Unity 不同，生境把世界状态交给**独立计算系统持续维护**。

- **集智俱乐部"世界模型读书会"**（8 月 7 日起每周五）：以"世界如何被表征、动力学如何被建模、内部模型如何服务于智能体"为主线，尝试建立世界模型统一框架——学界的"整理期"信号。

- **2026 世界机器人大会（8 月北京亦庄）**：中国电子学会世界模型专家委员会成立；"世界模型元年"从概念走向产品——机器人 1 秒预测未来状态 10 次、预演未来 2—3 秒，把行动代价降到最低；"千台级交付"成为部分厂商 2026 年目标。

- **陈博远（具身智能研究者）判断**：明年年底前数据采集方式与具身形态可能收敛；**18—24 个月内世界基座模型能力出现标志性阶跃；36 个月内实现多个真实场景应用落地**——与 GPT-3 → ChatGPT 的路径高度吻合。

## 五、趋势判断：七条主线

1. **范式转移确立**：从"预测下一个词"到"预测世界的下一个状态"。NSP 范式（Next-State Prediction）成为 2026 年技术共识，语言模型与物理世界理解之间的鸿沟成为主攻方向。

2. **世界模型"以 Agent 为中心"转向**：World Proxy（上海 AI Lab/浙大/NUS）标志世界模型的设计哲学从"预测得更准"转向"服务 Agent 规划、学习与自我改进"——L1/L2/L3 三层介入框架将成为后续工作的坐标系。

3. **评测全面"智能体化"**：HarnessEval-W、PlayWorld、Beyond Final Scores 共同指向——从"固定轨迹/黑箱分数"走向"长程目标 + 过程可追溯"；从"有没有做成"走向"怎么做成、哪里失败、经验是否复用"。

4. **Agent 自我进化从模型内部转向外部系统**：MemoHarness（改 Harness）、Knowledge-Centric Self-Improvement（攒知识库）、EnvHarness（进化环境）与 Schmidhuber 97 页综述合流——**"不更新权重也能进化"成为可落地的工程路线**，企业侧比频繁训练模型更易观察、测试与回滚。

5. **长程一致性的两条技术路线**：一条是**持久记忆**（Alaya-EVOKE），一条是**显式状态/连续时间**（Marionette、ODEWorld）——像素级自回归难以自行记住长程世界状态，可编辑状态层与连续时间建模成为解药。

6. **产业落地"硬场景深耕、软场景快拓"**：自动驾驶（特斯拉神经世界模拟器，每公里自动产生反馈数据）与人形机器人（3D 物理复刻 + 虚拟试错）是两大核心场景；工业巡检、低空救灾、气候预测、医疗仿真快速渗透。2026—2027 垂直专用模型率先商业化，2028 年后通用模型雏形显现。

7. **安全与信任成为新前沿**：具身智能体安全综述首次将"世界状态"列为独立攻击面；信通院《云上 Agent 基准度量模型》六维评估、Agent Memory Leaderboard（AML）开放锦标赛——**可信、可测、可审计**成为 Agent 规模化的前提条件。
