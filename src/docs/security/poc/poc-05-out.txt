## 3. 汇总判定

- 无空格路径下可直接注入（marker 写入）: 无
- 无空格路径下变量扩展生效: PERCENT（%CD% 在引号内被 cmd 预展开，stderr 可见；!CD! 延迟扩展默认关闭不生效）

结论口径：
  存在可注入/可扩展字符 → shell:true 在当前版本下仍是放大面，F-06 修复项（移除 shell:true）优先级不变。

  Node v24 官方 DEP0190 弃用警告原文：Passing args to a child process with shell option true can lead to
  security vulnerabilities, as the arguments are not escaped, only concatenated.
